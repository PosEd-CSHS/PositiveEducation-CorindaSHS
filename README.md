# Positive Education — Corinda SHS

Internal resources supporting Corinda SHS Home Group activities.

## Delivery context

The QLearn course is the navigation hub and is accessible to teachers. Teachers display and facilitate selected activities collaboratively with a mixed-year Home Group class of approximately 28 students from Years 7–12.

Home Group runs for 10 minutes at the beginning of each school day. Resources should therefore be quick to open, simple to explain, suitable for a broad age range and usable without requiring students to enter personal information.

## Repository structure

- `homegroup-lessons/` — fortnightly lesson and activity guidance
- `games/` — active whole-class Home Group games
- `character-strengths/` — character strengths directory and survey
- `brain-breaks/` — quick movement and reset activities
- `staff-learning/` — staff PERMAH learning resource
- `assets/site-config.js` — shared school-year dates and QLearn games hub link
- `archive/` — retired resources retained for reference only

## Annual rollover

Update the year and four term date ranges in `assets/site-config.js`. Active games read their weekly schedule from this shared file, so the dates should not need to be edited separately in every game.

Then check that weekly content banks contain one entry for each teaching week. Wordle and Connections currently contain 40 entries.

## Use and maintenance

These resources are for their stated internal Corinda SHS purpose. The QLearn course should remain the main entry point; this repository does not need a separate public home page.

Before deployment, test the current-week label, one full game, return links and score submission on the devices commonly used in Home Group rooms.
