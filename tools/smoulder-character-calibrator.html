🎯 Smoulder character calibrator

Dev-only tool for tuning a new "Where's Smoulder" special-edition character. Paste the character's draw function (or point it at an image), pick a size to preview against, and drag the sliders until the feet sit on the ground line and the whole figure is inside the dashed click box. Copy the finished line into that edition's EVENT_EXTRAS array. Reference figures on the right show the actual crowd student size range (26–80px) this game uses.

This tool never saves anything — copy the output line into the special edition's EVENT_EXTRAS array by hand, and add the matching draw function next to the other prop functions if it isn't there yet.
